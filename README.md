# SFirewall

A calm, partner backed self lock for macOS. SFirewall blocks the sites and apps you choose,
on a schedule or always, and texts your accountability partner if anyone tries to get around it.

## Download

Get the latest signed installer from **[Releases](https://github.com/markschwab17/sfirewall-releases/releases/latest)**
(`SFirewall-<version>.pkg`). It is signed with a Developer ID and notarized by Apple.

Requires macOS 15 or later, on Apple silicon or Intel.

## Install

1. Open the `.pkg` and follow the installer.
2. SFirewall opens its Setup window. Have your partner with you: they type a 4 digit code you
   never see. Nothing can be loosened later without that code.
3. Follow each Setup step (Messages, Accessibility, Allow in the Background). Each has an
   Open Settings button that takes you to the right place.

## Update

Download the newer `.pkg` from Releases and run it. Your settings and partner code are kept.
Installing an older version over a newer one is refused.

## Uninstall

Open SFirewall, Blocks window, Settings, **Uninstall SFirewall**. It needs your partner's code,
is refused while a Focus or Power block is running, and texts your partner first.
